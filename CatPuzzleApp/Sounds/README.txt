Original short UI tones synthesized for CatPuzzle (猫咪占领火星).
They are original works in this repository and ship under the same LICENSE
as the rest of the project. Filenames:

- sfx_excluded_mark.wav    single-tap places ×
- sfx_excluded_unmark.wav  single-tap clears ×
- sfx_cat_mark.wav         double-tap places a paw
- sfx_cat_unmark.wav       double-tap clears a paw
- sfx_start.wav            a new level begins
- sfx_cat_failed.wav       an illegal cat placement is rejected
- sfx_heart_broken.wav     the mistake limit is hit and the game is lost
